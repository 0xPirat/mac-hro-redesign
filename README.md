# Mac-HRO · Website-Redesign

Modernes, responsives Website-Konzept für Mac-HRO in Rostock. Die Seite bereitet die vorhandenen Informationen zu Apple-Beratung, Mac-Support, Training, Fernwartung, Sonos und Leih-Macs übersichtlich und interaktiv auf.

## Live-Demo

[mac-hro-rostock-redesign.smileypro.chatgpt.site](https://mac-hro-rostock-redesign.smileypro.chatgpt.site/)

## Funktionen

- Responsive Darstellung für Smartphone, Tablet und Desktop
- Interaktiver Service-Kompass
- Eigener Leih-Mac-Bereich mit Geräten, technischen Daten, Preisen und Verfügbarkeit
- Animierte Gerätebildschirme und Scroll-Effekte
- Kontaktformular mit vorbereiteter E-Mail
- Barrierearme Bedienung und Unterstützung für reduzierte Bewegung

## Lokal starten

```bash
python3 -m http.server 8000
```

Anschließend `http://localhost:8000` im Browser öffnen.

## Technischer Aufbau

Die Website ist ohne Framework umgesetzt und besteht aus semantischem HTML, modernem CSS und Vanilla JavaScript. Die Inhalte stammen aus dem bestehenden öffentlichen Mac-HRO-Webauftritt und wurden gestalterisch neu strukturiert.
